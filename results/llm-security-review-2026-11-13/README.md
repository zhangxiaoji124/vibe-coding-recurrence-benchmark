九项均通过本次脚本断言。涉及模型的七次请求实际返回 deepseek-flash，完整回复见 evidence.json。请求只包含合成代码和文字约束。

## 实验边界

- L1 用作者角色提示词模拟自审，候选代码由脚本提供。L2 是独立请求，与 L1 使用同一服务模型。
- R 使用写在脚本中的合成仓库契约。S 验证同一进程内保留上下文。C 使用预编写修正版本验证循环转移。
- AST 规则针对该合成函数，执行验证覆盖六个指定输入。本轮结果适用于这组流程检查。

## 复跑

在本目录运行 `python run_experiments.py --out evidence-rerun.json`。需要已配置的 `DEEPSEEK_API_KEY`，以及本机已有的 `susvibes_harness`。如果 harness 在其他目录，可传入 `--harness`。在线模型输出可能随重跑变化。
